# 🎮 Tic Tac Toe Game – Frontend Project  

A modern and interactive Tic Tac Toe game built using HTML, CSS, and JavaScript with a glowing dark-theme UI.

🔗 Live Demo: https://sanket745tic-tak-toe.netlify.app/

---

## ✨ Features

- Two-player gameplay  
- Win and draw detection  
- Reset game button  
- Stylish neon glow UI  
- Responsive design  

---

## 🛠 Tech Stack

- HTML5  
- CSS3  
- JavaScript (Vanilla JS)
